## Deviations from SPEC.md

- M0 exit is not fully met: the 27B measurement is partial (prefill, first token, decode and W measured; tool calls through the AI SDK measured only on the 1.7B) because the memory guard stopped the 27B. The tool-call probe and the 8k cold probe on the 27B wait for a run with other apps closed.
- Files not in SPEC 5's layout: `scripts/llm-measure.ts` (the M0 measurement), `scripts/lib/results.ts` (README Results rendering), `engine/tests/features/micro.py` (micro-world builder).
- Model design: period intercepts are a cause intercept plus penalized period deviations (an unpenalized intercept per cause and period diverges for retirement, which has no events in some periods); the tenure spline is a natural cubic spline with knots at the 20/40/60/80% training quantiles, giving 3 basis functions plus the intercept.
- HRIS records carry `contract_end_date` (needed for `fixed_term_days_remaining`, which 6.4's column list omitted) and a `rescission` record type for rescinded terminations; payroll lines carry `recorded_at` (the vendor file's delivery time). The data dictionary (M2) documents them.
- Agent connections are routed server-side (`/agents-ws/analyst` and `/agents-ws/workspace`): the Worker authenticates, picks the instance from the verified principal and forwards with an internal header, instead of `routeAgentRequest` with an instance-name check in `onConnect` (SPEC 4.3). Same guarantee, no instance name ever leaves the server.
- The repair runs inside RoutineWorkflow after the mapping approval rather than in a separate RepairWorkflow; ReviewWorkflow is not built yet (reviews are approved directly on the WorkspaceAgent with the same rules).
- Narration streams to the chat after the grounding check (tool results stream as they complete), so no ungrounded number is ever shown.
- SHA-256 in the Worker is a small synchronous TypeScript implementation (`src/shared/sha256.ts`, tested against node:crypto) so a log row and its hash are written in one synchronous block.
- Beat 2 magnitudes (SPEC 6.5 targets) on Engineering at 3 months: Calendar -0.7 (target -3.0 to -0.8), Composition +0.2, Input data +0.3 (target -1.5 to -0.3), Model +0.1, Definition -0.3 (target -1.5 to -0.3). Input data is positive because the 12 late terminations raise the organization's recent voluntary rate, which the contagion feature shrinks every teammate toward, more than removing 13 people lowers the sum; Calendar is smaller because the fitted Fourier seasonality is weaker than the generator's month effects. The allowed knobs cannot change either, so the realized values are reported, not tuned.
